The palette's shortcut is Ctrl+Alt+,, or ⌥⌥, on a Mac. The same actions are in the IDE's own Find Action and Keymap under Tools | Penstock, so a shortcut can be bound to any of them the way the IDE binds its own. The palette's shortcut is Find Action in Diagram in the keymap, and Export keeps Cmd/Ctrl+Shift+C. See Shortcuts.
