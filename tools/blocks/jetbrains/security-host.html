• Secrets are kept in the IDE password safe, once for each profile.
  • The Run Penstock commands in the tool window, and the preDeploy and postDeploy hooks of an IDE deploy, run only in a project marked as trusted. Without a penstockw in the project, the IDE runs npx @kern0x1b/penstock-cli, which downloads the command from npm the first time.
  • A private certificate must be trusted by the Java runtime of the IDE. Penstock never skips the check.
  • The connector download uses the IDE proxy settings.
