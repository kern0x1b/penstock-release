• Passwords and client secrets are kept in VS Code's secret storage, once for each workspace, profile and field.
  • The preDeploy and postDeploy hooks of penstock.yaml run only in a trusted workspace.
  • Files are read and written only inside the workspace folders, or where you chose in a dialog.
  • The connector catalogue is downloaded on demand into ~/.penstock/connectors, with a cap of 64 MB.
