Undo and redo

The text document is the only history of a diagram, and the diagram's own undo and redo keys and buttons ask VS Code to undo and redo. So VS Code's keys for Undo and Redo move the diagram, and so does Edit | Undo.

Any other action

Every action of the editor is a command named penstock.action. followed by the action, for example penstock.action.deploy. Bind a key to one in Keyboard Shortcuts: search for Penstock, or for the name the action has in the editor, such as Auto layout. Use the penstockEditorFocused condition to bind it only in the editor, as the four editor keys above do.

In your code

Press F2 on a name that diagrams and code share (a job type, topic, bean, message, signal, process, decision, form or error) to rename it in both. Pro. Navigation commands use VS Code's standard keys: Go to Definition (F12) and Find All References (Shift+Alt+F12) reach the diagrams, and a click on a code lens opens the diagram. See Code links in VS Code.

Common problems

A key does nothing in the diagram.
The editor must have focus. Click an empty spot on the canvas. An action the diagram has switched off does nothing.
Ctrl+Shift+C does not export.
It is bound only in a Penstock editor. In any other panel VS Code's own binding applies.
