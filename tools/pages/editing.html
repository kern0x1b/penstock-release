Add an element

  1. Drag an element from the palette at the left edge of the canvas and drop it where you want it.
  2. Type to give it a name. Double-click the element to rename it later.
  3. To connect it to another element, select the first one and drag from the arrow icon of the small pad beside it onto the second.

Or let Penstock add the next element for you: select an element and use the pad beside it. The pad appends the element you choose, already connected. Its Create element catalogue lists every element by what it is for. See BPMN elements.

Change an element into another

  1. Select the element.
  2. Press the wrench on its pad.
  3. Pick what it should become. A task can become a service task, a start event a message start event, an exclusive gateway a parallel one.

The name, the connections and the properties that still apply are kept.

Undo and redo

Undo and Redo are the first two buttons on the toolbar. They step through every change in the order you made it. While a token simulation runs they are switched off, so a preview cannot change your file.

Copy and paste

Copy and paste use the system clipboard, not a clipboard private to one diagram. So you can copy a pool from one diagram and paste it into another diagram that is open in another tab. Copy and Paste are in the More menu. Pasting from the toolbar has no mouse position, so the elements land in the middle of the view.

The minimap

Open More and choose Minimap. A small overview of the whole diagram appears. It helps on large diagrams.

Right-click

The context menu of an element holds the editing actions and, when they apply, Go to the Java class a task names, and the Pro actions that link to your code. See Code links.

Go to a Java class

Right-click a task that names a Java class. That is a Camunda 7 camunda:class, a delegate expression that unwraps to a full class name, or a listener that names a class. The menu offers Go to with the class name. It opens the file. Penstock finds the class by name and package in your own sources.

Hover

Rest the pointer on an element and a card shows its id, type, name and flows. On a service task it also shows the implementation. On a user task it shows the assignee and candidates.

Common problems

I cannot drag or delete anything.
Token simulation is on. Press Simulate again to stop it.
Paste does nothing.
Copy something first. Select one or more elements, open More and choose Copy.
The Go to entry is missing.
The task names no class, or the class lives in a library instead of your own sources.
I dropped an element in the wrong place.
Press Undo. Or, if you already did other things, drag it back.
