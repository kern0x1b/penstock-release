What it is

An element template is a JSON file. It says: "this task is a Slack message, and it needs a channel and a text". When you apply it, the properties panel shows only those two fields and Penstock writes the technical settings for you. Penstock uses the Camunda template format. For the format itself, read Camunda's documentation.

Where Penstock finds templates

Two places, and nothing else in the project is scanned:

  • A folder named .camunda/element-templates, next to the diagram or in any folder above it, up to the project root. This is where the Camunda Modeler keeps templates. You do not have to list it.
  • The files and folders listed under elementTemplates in penstock.yaml, relative to the project root. A folder is read whole, with every .json file in it and below it.
elementTemplates:
  - templates/connectors
  - shared/payment-task.json

Like the rest of penstock.yaml, the list can differ per folder. The file nearest the diagram wins. See penstock.yaml.

A file may hold one template or an array of templates. Both work.

What is skipped without an error

  • A path that no longer exists.
  • A file larger than 10 MB. A warning goes to the IDE log.
  • A file that is not valid JSON. The error goes to the IDE log with the path.

Penstock re-reads a file when its modification time changes, so an edited template is picked up without restarting the IDE.

Apply a template

  1. Select a task or event in a Camunda 7 or Camunda 8 diagram.
  2. In the properties panel, use the template chooser at the top. Pick a template.
  3. Fill in the fields the template shows.

The element records which template it came from. Under Camunda 7 that is camunda:modelerTemplate. Under Camunda 8 it is zeebe:modelerTemplate. The Classic profile has no template support.

The connector browser

Camunda publishes ready-made connector templates: Slack, e-mail, REST, and many more. Penstock has a browser for them.

Open it

  1. Open a Camunda 8 diagram.
  2. Open More and choose Templates…. A dialog called Connector Templates opens.
  3. The first time, it says Downloading the connector templates from GitHub…. Wait a moment.

The templates are not bundled with the plugin. They are downloaded from Camunda's public camunda/connectors repository on GitHub, and kept in ~/.penstock/connectors/. The IDE and the command line share that folder. Penstock asks GitHub at most once a day. It sends no credentials, no cookies and no project data. Opening a diagram never downloads anything. See Security and privacy.

Find a template

  • Type in Search name, description, keyword.
  • Use the Element type and Category lists on the left. The number beside each is how many templates it holds.
  • Press Installed only to see what your project already has.
  • Templates that need a newer Camunda engine than the diagram targets are hidden. Press Show N for newer engines to see them.
  • The line at the top says which release you are looking at, for example Camunda connectors 8.8, checked 10:14. Press Check for updates to ask GitHub now.

Each card shows the name, a short description, the element type, the version, and the Camunda version it needs. Details opens the whole template: its fields, grouped, and a link to the documentation.

Install one

  1. Press Install on a card, or Install template in its details.
  2. A save dialog opens with the template's own file name. Save it into .camunda/element-templates, or into a folder your elementTemplates list already names. Cancel writes nothing.
  3. If penstock.yaml has no elementTemplates list yet, the file you saved is added as its first entry. A list that exists is left alone.
  4. The open diagram uses it at once. You do not need to reopen it.

A message says Template "…" installed. The card then says Installed and its button is off.

A diagram that names a template you do not have

When a diagram uses a connector template that is not in the project, Penstock looks in the downloaded set. If it is there, the diagram uses it. If not, a small badge on the element says Template not downloaded with a Download button. Press it to fetch the catalogue.

From a terminal

penstock connectors                 # list the current templates
penstock connectors resolve io.camunda.connectors.HttpJson.v2
penstock connectors --refresh       # ask GitHub now

See Every command.

Common problems

A template does not appear.
Check three things in this order. The diagram's engine must be Camunda 7 or Camunda 8, not Classic. The file must be in a .camunda/element-templates folder at or above the diagram, or under a path in elementTemplates. The file must still exist. penstock doctor reports a listed path that is missing. Then read the IDE log: a file that is too large or not valid JSON is skipped with a message.
There is no Templates… item.
The connector browser is only for Camunda 8 diagrams.
The browser says the connector templates could not be downloaded.
Penstock could not reach GitHub. Check the network and the IDE proxy settings, then press Retry. If it worked before, Penstock uses the templates it already downloaded. It tries again automatically after a while.
Install says nothing was written.
You cancelled the save dialog. Nothing is written when you cancel.
