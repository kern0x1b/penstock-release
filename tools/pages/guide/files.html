In your home folder

Penstock keeps its personal files in ~/.penstock. If the environment variable PENSTOCK_HOME is set, they are under that folder instead. Every tool on the machine shares them.

FileWhat it is
preferences.jsonYour toolbar choices, whether the tour was seen, the editor theme, the width of the sidebar and the tab you left selected in each editor, whether the palette is folded, Sketchy drawing, tree or flat view of the project model, the last export format, the suggestion switches, and the AI chat: where it is shown, which agents are on and the model of each. Readable only by you, and replaced whole, never half written. A file that cannot be read is kept as preferences.json.bak before a new one is written. See penstock.yaml.
chats/<project>/The chats of the AI agent, one file for each chat with its title, its messages and the files it touched, in a folder for each project. Readable only by you. Deleting a chat in the editor removes its file. See AI chat.
agents/The list of agents from the ACP Registry as last fetched, with its icons; the agents Penstock installed for you; and the models each agent offered the last time they were read. See AI agents.
agent-hub/A small record for each project, so every window and tool finds the one agent session the project shares: a port on this machine (127.0.0.1) and a token. Readable only by you, and removed when the session ends.
license.jsonThe signed licence token and a clock mark, never a key, a tier or a date you could edit. Readable only by you. See Buying and signing in.
clock.json, pipeline.jsonThe latest time the machine has seen, kept beside the licence so a clock set back is noticed, and the short-lived token of a pipeline run.
trusted-projects.jsonThe projects you have trusted to run a deploy hook, the project's command line and its lint rules. Trusting in one tool trusts in the others. Settings in your tool list them, and penstock trust --list prints them.
connectors/<release>/The Camunda connector templates downloaded from GitHub.
wrapper/dists/<version>/The command line versions the wrapper downloaded.
test-builds.jsonA list of test builds a test-case run deployed, so the next run can remove what an interrupted one left.

Not in a file

The password or client secret for a deployment profile lives in the secret store of your tool. It is never written to a file.

How to remove everything

  1. Remove Penstock from your tool. See below.
  2. Delete ~/.penstock.
  3. In your projects, delete the files above that you do not want.
{{host:uninstall|Remove Penstock from your tool}}

What you see

  • After a few days of use, ~/.penstock holds preferences.json and license.json, and maybe connectors, trusted-projects.json and, if you used the AI chat, chats and agents.
  • Your projects hold penstock.yaml and, if you ran init, the wrapper files.

Common problems

My toolbar differs between two computers.
preferences.json is per machine. It does not sync.
I want the settings somewhere else.
Set PENSTOCK_HOME to another folder, for example on a shared drive. Then every tool uses that folder.
Git shows penstock.local.yaml as new.
Add it to .gitignore. penstock init does this for you.
