What it is

CMMN is a standard for case models, where the work is not a fixed path but a plan whose items start when something allows them. Penstock opens .cmmn and .cmmn11.xml files in every host. The viewer is free with no time limit.

What the viewer shows

  • Stages, and human, process, case and decision tasks.
  • Milestones and event listeners.
  • Entry and exit criteria, joined to the plan items they wait for.
  • The required, repeating and manually activated markers.

Elements are drawn where the file puts them. A file without a diagram is laid out from the sentries.

A read-only Properties tab shows what each element is and what starts it. The viewer says plainly that editing is not supported, and has an Open as text button.

The checks

Six rules in the family cmmn fill the Problems tab of the viewer and run in penstock check, which takes .cmmn files and folders that hold them. Each rule has a page.

RuleWhat
cmmn/duplicate-idAn id used twice.
cmmn/definition-ref-missingA plan item with no definition.
cmmn/dangling-sentry-refA criterion that points at nothing.
cmmn/dangling-on-partAn on-part that points at nothing.
cmmn/task-without-targetA task that names nothing to call.
cmmn/no-case-plan-modelA case without a case plan model.

A case model that would expand without end, such as a stage that contains itself, stages that contain each other or a fan-out of stages, is read once per stage on the path and at most 10000 plan items. The warning cmmn/plan-truncated says what the viewer left out.

Draw it as a picture

penstock export draws a case model as SVG or PNG, one file per model. See Export.
