1. Get Penstock

Penstock comes in more than one form. The features are the same in each. Pick the one you use.

{{host:get-penstock|Get Penstock}}

In VS Code, run this in a terminal, or open the extension's page and press Install:

code --install-extension penstock.penstock

2. Try the example

The quickest way to see everything work is the example: a small order process with workers, a decision, a form and test cases. The example project explains every file. Write it into an empty folder.

{{host:write-example|Write the example}}

3. Look at it, check it, deploy it

  1. Open src/main/resources/order-process.bpmn in the editor. The diagram appears.
  2. Press Check. A card lists what is wrong. A fresh example has nothing wrong. See Diagram check.
  3. Press Deploy. A popover opens, and the first time it asks for the engine address. Enter it, save, and deploy again. See Deployment.
{{host:first-check-deploy|Do it in your tool}}

Start with your own diagram

  1. Open a .bpmn file. If you have none, create a file called process.bpmn and open it. An empty file is fine.
  2. If the diagram says nothing about its engine, one line appears above the canvas: Which engine runs this diagram? Press Camunda 8, Operaton, CIB seven, Camunda 7, Flowable, Activiti or Classic BPMN. The answer is written to penstock.yaml in the project root, which is created if there is none. It is asked once.
  3. Draw. Drag elements from the palette on the left, or click an element and use the small pad next to it. Editing a diagram shows how.
  4. Select an element and fill in its properties in the Properties tab on the right. The properties panel explains the groups.
  5. Press Check. Fix what it lists, in the card or in the Problems tab.
{{host:open-a-diagram|Open a diagram}}

What you see

  • Toolbar along the top. Undo and Redo are on the left. Deploy is on the right. Everything else is in the More menu. See The toolbar and the More menu.
  • Palette beside the canvas, with the elements you can draw.
  • Canvas in the middle. It takes the theme of your tool, and the diagram opens fitted into it.
  • Sidebar on the right, with a row of tabs: Properties, Scenarios, Problems, Comments, Monitor and Code. See The sidebar.
  • Editor tabs below: the diagram, and Text for the raw XML of the same file.

Common problems

Deploy is missing from the toolbar.
Deploy is shown for Camunda 7, Camunda 8, Operaton and CIB seven projects. Classic BPMN, Flowable and Activiti projects have none. Change the engine in penstock.yaml.
The question about the engine did not appear.
It appears only for an empty diagram. A diagram that already says which engine it is for, or a project with engine in penstock.yaml, is not asked.
The example was not written.
An example is written only into an empty folder, so it never overwrites your files.
