The trial

The first time you use Penstock on a machine, that machine gets 30 days of Pro. You do nothing. When the trial ends, the machine is on the Free plan. The trial is stored on the machine, in ~/.penstock/trial.json. It needs no network. A pipeline gets no trial.

Buy Pro or Team

  1. Choose to buy in your tool, or press a Buy button on the Plans page.
  2. The checkout opens in your browser, on Polar's page. Choose the billing period there.
  3. Pay. Penstock notices the payment by itself and sends a sign-in code to the address that paid.
  4. Type the code in. The licence is active. There is no key to copy.

You can also reach the same step from a paid feature: the message that explains it has a Buy button.

Sign in on another machine

  1. Start signing in in your tool.
  2. Type the address you bought Penstock with. A key works in the same field too.
  3. An e-mail brings a code. Type it in.
  4. Penstock finds your best licence and activates it on this machine.
{{host:signin-steps|Sign in from your tool}}

Every tool on a machine shares the licence. Sign in once and all are licensed. They read ~/.penstock/license.json.

How many machines

A licence covers a number of machines at once. Signing in again on the same machine, for example after reinstalling your tool, reuses its place. It does not take a new one. When every place is taken, signing in lists the machines and when each was activated. Pick the one to free, and this machine takes its place. You can also release a machine by hand.

When the licence is checked

  • Once a day, in the background.
  • It keeps working for 30 days without a connection. The status shows how many days are left.
  • After 30 days without a check, the machine falls back to Free until it connects once.
  • If the subscription ended, or the licence was released from another place, the machine falls back to the trial, or to Free when the trial is over.

In a pipeline

A pipeline does not sign in. Give it the licence key as a secret named PENSTOCK_LICENSE. The key is checked, and it takes no machine's place. The pipelines that penstock init --ci writes already pass it, when the machine that ran the command has Team. Without Team on the machine, init --ci writes a pipeline that runs only the free checks. See Pipelines, reports and the bot.

Free Pro for students, teachers and open-source maintainers

Penstock offers Free Pro to students, teachers and open-source maintainers. When the application address is set, it appears in three places: the licence dialog (a link Free Pro for students, teachers and open-source maintainers: apply), the message that explains a paid feature (a button Apply for Free Pro), and the output of penstock license. While no address is set, nothing about it is shown.

The application address is not yet published on this page. If you qualify and see no link, open an issue on the support tracker and say which group you are in.

What you see

  • After signing in: Penstock Pro is active on this machine.
  • The status of the machine says Pro or Team instead of Pro trial.

Common problems

"There is no Penstock licence bought with that address."
Sign in with the exact address you paid with. Or buy again.
"That code is wrong or has expired."
Ask for a new code. You have three tries per code.
"Signing in needs a terminal to answer in."
You ran the command line sign-in in a place without a terminal, for example a CI job. In a pipeline set PENSTOCK_LICENSE instead.
"PENSTOCK_LICENSE is not a valid Penstock key."
Copy the key again. Check there is no space or line break around it.
Every machine is in use.
Pick one to free when signing in, or release a machine you no longer use.
The licence service could not be reached.
Check your network and proxy. An active licence keeps working for 30 days offline.
