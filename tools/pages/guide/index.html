How every page is built

Each page starts with one sentence that says what the feature is for. Then come numbered steps, then what you should see, then the problems people meet most often and how to fix them. A tag shows if a feature is free, or needs Pro. See Plans and licence.

The guide covers the plugin and the penstock command line. Both read the same penstock.yaml and give the same answers.
