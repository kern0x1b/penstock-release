How the documentation is organised

The Guide on these pages describes what Penstock does. It is written once and is the same in every tool. Where a step depends on your tool, a small block on the page shows it for each tool.

Each tool has its own section for what is special about it: how to install it, where things are, and the features that need it. Pick yours at the end of this page.

Each page starts with one sentence that says what the feature is for. Then come numbered steps, what you should see, and the problems people meet most often. A tag shows if a feature is free or needs Pro. See Plans and licence.
