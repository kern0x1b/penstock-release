Basics

What is Penstock?

A BPMN, DMN and form editor for Camunda 7, Camunda 8, Operaton and CIB seven, with checks, deployment, tests and more. It comes as a plugin for JetBrains IDEs, as an extension for VS Code, as a penstock command line with an MCP server, and, with penstock web, as an editor in a plain browser (Penstock Web). A desktop app is built from the same editor and is not part of a release yet. Diagrams stay in your project and in version control. See Getting started.

Which tools can I use?

Any JetBrains IDE from 2024.2 that has JCEF, which the standard downloads do, VS Code 1.88 or later and the editors built on it (Cursor, Windsurf and VSCodium), and the penstock command line, which needs Node.js 22.22 or later. See Installing in a JetBrains IDE and Command line.

What happened to "Camunda BPMN Editor"?

It was renamed Penstock in 2026. It is the same plugin with the same id, so it updates in place. Nothing needs to be reinstalled.

Is there a free version?

Yes. The editors, the properties panels, templates, token simulation, the check, lint, comments, trace paths, deploy, Monitor, export, share and import are free. Pro and Team add what only Penstock does. Every machine starts with 30 days of Pro. See Plans and licence.

Which engines work?

Camunda 7, Camunda 8, Operaton and CIB seven, plus plain BPMN 2.0. See Engines.

Does Classic mode write vendor-neutral BPMN?

Yes. Classic loads the plain bpmn-js editor and no Camunda extension, so nothing it edits adds Camunda attributes. Data inputs and outputs are written as bpmn:ioSpecification. See The properties panel.

Money and licence

What do I need for a pipeline?

Team. One rule: Pro on your machine, Team in a pipeline (any run with CI set). A pipeline gets no trial. See Buying and signing in.

Do I have to copy a licence key?

No. Buying opens the checkout, notices the payment and signs you in with a code sent to your e-mail. A key still works if you want to type one.

Does it work offline?

Yes, except deploy, engine questions, the connector download and the licence check. A licence works 30 days without a connection.

Can students and open-source maintainers get Pro?

Penstock offers Free Pro for students, teachers and open-source maintainers. See Buying and signing in.

The AI chat

Does Penstock include an AI model?

No. The AI chat starts an agent of your choice, such as Claude Code, Codex, Gemini CLI or OpenCode, or any agent of the ACP Registry, on your machine and on your own account. Penstock gives it its MCP server so it can read your diagrams, rules, scenarios and code links. See AI chat and AI agents.

Can the agent change my files without asking?

No. Every write is asked before it happens, and the answer holds for that one question. A change to a diagram is drawn on the canvas first, and you accept or reject each change. See AI chat.

How do I turn the AI chat off?

Set AI chat to Off in the agents screen. The input, the chats, the Chat tab, the toolbar button and the agent process are gone. Another choice there puts the conversation in the sidebar instead. It is kept in ~/.penstock/preferences.json for every tool. See AI agents.

Is the AI chat free?

The input and the chats are shown to everyone. Sending a message needs Pro, and in a pipeline Team. The suggestions that Penstock makes without a model, the next element at a dead end and the name, source or expression for a field, are free. See Plans and licence.

Privacy and safety

Does the plugin send my diagrams anywhere?

Only to the engine you configure, when you deploy, and to the agent you chose, when you use the AI chat. There is no telemetry. The full list of network use is in Security and privacy.

Where do my passwords go?

To the secret store of your tool, once for each profile. Never to a project file, and never to the web page in the editor.

Is it safe to run scenarios against my engine?

Only on an engine you mark deployment.forTests: true, or a local one you confirm. It removes what it deployed. See Scenarios.

Editing

Can I leave notes on a diagram?

Yes. Comments are free and are kept in the diagram file, so they travel through Git with it. See Comments.

How do I see every path through a step?

Select it and use Trace paths. The rest of the diagram is dimmed. See Trace paths.

Can I try a decision table before I deploy it?

Yes. The Try tab of the decision editor runs the table against values you type and says which rules match. See The DMN editor.

Where is the Comments tab, or the Try tab?

Each editor has its own tabs in the sidebar. A diagram has Properties, Chat, Problems, Scenarios, Comments, Code, Monitor and Debug. A decision has Properties, Chat, Problems and Try. A form has Properties, Chat, Preview and Problems. The Chat tab is there while the AI chat is on. See The sidebar.

Where is the save button?

There is none. Every change is written to the file at once. A file with no layout is laid out in memory when it opens and is written only once you edit it. See The BPMN editor.

Why did the view not move when I opened the sidebar?

The first view of a diagram fits the canvas, and after that the view is yours: resizing the window, showing a sidebar or folding the chat never re-fits or re-zooms it. Fit diagram does it on demand. See Editing a diagram.

Can I hide the sidebar to see more of the diagram?

Yes. Focus canvas in the More menu hides the sidebar, and a second use brings it back. See Editing a diagram.

Can I see the raw XML?

Yes. The Text tab at the bottom of the editor. Both tabs edit the same file.

Can I jump from a delegate class name to the class?

Yes, and it is free. Right-click the task and choose Go to. See Editing a diagram.

Where do the toolbar choices live?

In ~/.penstock/preferences.json, for every tool on your machine. Never in penstock.yaml. See The toolbar and the More menu.

Why did auto layout move everything?

It draws the whole diagram again from the process model. Press Undo to take it back. See Auto layout.

Command line

Do I need the command line?

No. The editor in your IDE works alone. The command line adds pipelines, scripts and the MCP server. See Command line.

Which Node.js version?

22.22 or later, with npm.

What are the exit codes?

0 all well. 1 findings, refusal or failure. 2 crash.

Moving and sharing

Can Penstock move my running Camunda 7 instances?

No. Instances can finish on Camunda 7 or be moved with Camunda's Data Migrator. See Camunda 7 to 8.

How do I send a diagram to someone who has no editor?

Use Share as HTML. It makes one file that opens in any browser.

Can I bring in a Visio or draw.io diagram?

Yes. Import a diagram handles draw.io, Visio, Signavio and Bizagi files.

How do I report a bug?

Open a GitHub issue with the versions and a .bpmn file that shows it. Security problems go to SECURITY.md.
