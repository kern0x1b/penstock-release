Polish, Italian, Dutch, Turkish, Ukrainian, Traditional Chinese, Czech, Indonesian and Vietnamese came with 26.11.0. They were translated with a model and have not been reviewed by native speakers. If something reads wrongly, tell us what to fix.

How the language is chosen

  • The editors and the plugins follow the language of the tool or the browser.
  • The command line takes --lang <tag>. Without it, LANG, then LC_MESSAGES, then LC_ALL decide, and English is the answer when none matches. A saved language is used too.
  • A regional tag reads as its language: nl-BE, pl-PL and it-CH give Dutch, Polish and Italian. Values such as cs-CZ, id-ID, vi-VN, LANG=cs_CZ.UTF-8 and the legacy Java code in for Indonesian work as well.
  • Traditional Chinese uses Taiwan wording. It is chosen by zh-TW, zh-HK, zh-MO and zh-Hant. zh-CN and zh-Hans stay Simplified.

Common problems

The interface is in English.
The language of your tool, browser or shell is not one of the 18. English is the fallback. On the command line, pass --lang.
