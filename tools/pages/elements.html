Add an element

  1. Look at the palette, the strip at the left edge of the canvas. It has the elements most diagrams need.
  2. Drag one onto the canvas. Or click it, then click on the canvas.
  3. For any other element, press Create element at the foot of the palette. Type to search, or open a group.

The same catalogue opens from the pad of an element you have selected. There it appends the element you choose to the selected one, already connected.

The catalogue

Tasks

TaskAn unspecified step. Often a placeholder.
User taskWork a person has to do.
Service taskAutomated work done by a job worker or a connector.
Business rule taskEvaluates a business rule, usually a DMN decision.
Script taskRuns a script. On Camunda 7 the script can open as an editor tab. See Scripts in their own tab.

Gateways

Exclusive gatewaySends the token down one path, chosen by data.
Parallel gatewaySplits into parallel paths, or joins them.
Event-based gatewayFollows the path of whichever event happens first.

Sub-processes

Call activityCalls another process, like a function call.
TransactionA sub-process that completes as a whole, or is compensated.
Event sub-processA sub-process started by an event in its scope.
Sub-process, collapsedShown as one box. Double-click to open it in its own view.
Sub-process, expandedDrawn inline, with its contents.
Ad-hoc sub-processActivities run in any order, any number of times. Collapsed or expanded.

Events

Events are grouped by where they sit in the flow, because the same trigger means different things in each place.

Start eventsWhere a process or path begins.
Intermediate catch eventsWait for something to happen, then continue.
Intermediate throw eventsSend something, then continue.
Boundary eventsReact to something while a task runs. An interrupting one cancels the task. A non-interrupting one leaves it running.
End eventsWhere a path ends.

Inside each group are the triggers BPMN defines: message, timer, error, escalation, signal, compensation, conditional, link and terminate. Only the ones that are allowed in that place are offered.

Data and participants

Data object reference and data store reference are drawn as in the palette. A pool stands for an organisation or a system. Two pools in one diagram make a collaboration. Only a message flow may cross between pools. Lanes divide a pool by role or department. They carry no meaning when the process runs.

Change an element into another

Select it and press the wrench on its pad. The menu offers what the element can legally become. The name, connections and properties that still apply are kept.

What changes with the engine

The palette and the catalogue are the same for every engine. What changes is what the properties panel offers and which namespace is written into the file. See Engines.

Common problems

I cannot find an element in the palette.
Use Create element. It has every element.
My boundary event will not attach.
Drop it on the border of a task or sub-process, not inside.
I need a Camunda-specific task, for example a connector.
Use an element template on a service task.
