The map

WhereWhat is there
The editor of a .bpmn, .dmn or .form fileThe toolbar (Auto Layout, Check, Simulate, Monitor, Scenarios, the More menu, Deploy), the palette, the canvas, the properties panel and the check card. See The BPMN editor.
Tabs at the foot of the editorBPMN Editor and Text. See The editor in the IDE.
The Penstock tool window, left sideYour project as a tree, the Run Penstock menu, deploy, Check Workers, the migration. See The Penstock tool window.
The Run windowThe output of the Run Penstock actions and of test-case runs.
The gutter of a Java or Kotlin file, and of a test-case fileIcons that jump to the tasks that use a string, and green triangles that run a test case. See Code links in the IDE and Tests in the IDE.
Above a worker, delegate, bean or testCode Vision: which tasks it runs, how many tests reach it, how much of a process a test covers.
The context menu of a diagram elementEditing actions, Go to a class, Go to Implementation, Find Usages in Code, Run Tests, Debug Tests.
The Tools menuPenstock Licence…. See Licence in the IDE.
The status barThe licence: Penstock Free, Penstock Pro trial: 27d, Penstock Pro or Penstock Team. Click it for the licence dialog.
The IDE's diff windowTwo diagrams instead of two blocks of XML, for a .bpmn file. Pro. See Diagram diff.
The IDE's SettingsNothing of Penstock's own. There is no Penstock page in Settings. The project is set up in penstock.yaml. See penstock.yaml. The open-source notices are on the third-party notices page.
NotificationsWhat's new after an update, a legacy settings file that can move to penstock.yaml, a file Penstock cannot parse.

What you see

A JetBrains IDE with Penstock has a Penstock icon on the left tool window bar and, after you open a diagram, a toolbar and a properties panel inside the editor.

Common problems

Check the table above. Some actions are in the More menu of the editor. See The toolbar and the More menu.

Right. The project is set up in penstock.yaml, and the personal choices are in ~/.penstock/preferences.json.
