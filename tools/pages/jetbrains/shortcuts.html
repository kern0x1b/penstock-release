In the diagram editor

KeyWhat it does
Cmd+Z / Ctrl+ZUndo.
Cmd+Y / Ctrl+YRedo.
Cmd+C / Ctrl+CCopy the selection.
Cmd+V / Ctrl+VPaste.
DelDelete the selection.
Cmd+Shift+C / Ctrl+Shift+CCopy as image: the selection, or the whole diagram when nothing is selected, as a PNG on the clipboard.
Mouse wheel with Cmd or CtrlZoom the canvas.
EscClose a dialog.

In your code and in the tool window

KeyWhat it does
Cmd+click / Ctrl+click on a stringGo to the diagram element it names. Same as Go to Declaration. Pro. See Code links in the IDE.
The IDE's own shortcut for Find UsagesIn the tool window, on a node: find the code that names it.
The IDE's own shortcut for Go to ImplementationIn the tool window, on a worker: open its implementation.
The IDE's own shortcut for CopyIn the tool window: copy the id of the node.
Enter or double-clickOpen the selected node of the tool window.

The IDE's own shortcuts depend on the keymap you chose. Look them up in Settings | Keymap. Penstock does not define shortcuts of its own for them.

What you see

The keys above show next to their entries in the context menu of the editor and of the tool window.

Common problems

A key does nothing in the diagram.
The canvas must have focus. Click an empty spot on it. During a token simulation, keys that edit the diagram are switched off.
Cmd/Ctrl+click does nothing on a string.
Code links need Pro, and the string must be a name a diagram uses.
