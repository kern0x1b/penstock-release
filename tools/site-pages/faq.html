Basics

What is Penstock?

A visual editor for BPMN, DMN and Camunda forms that runs inside JetBrains IDEs and VS Code, with a command line that runs the same checks in your pipeline. It works with Camunda 7, Camunda 8, Operaton and CIB seven.

What happened to Camunda BPMN Editor?

It was renamed Penstock in 2026. It is the same plugin from the same author, with the same plugin ID, so it updates in place and nothing needs to be reinstalled.

Why did the version number jump from 2.4.1 to 26.9?

Since September 2026 releases are numbered by the calendar: YY.M.N. Version 26.10.2 is the second release of October 2026.

Is Penstock affiliated with Camunda?

No. It is an independent product. Camunda is a trademark of Camunda Services GmbH, and the name is used only to say which engines Penstock works with.

Free, Pro and Team

Is it really free?

Yes, with no time limit. The editors, properties panels, check and bpmnlint, deploy, Monitor, token simulation, export, share and import are free. See the comparison.

What do I get with Pro?

What only Penstock does: auto layout, flow analysis, code links, scenarios and test-case runs, the visual diagram diff, converting Camunda 7 to Camunda 8, and sending messages in the AI chat. Pro is {{price:pro:month}} a month or {{price:pro:year}} a year. Team adds the same inside a pipeline, at {{price:team:month}} per seat a month.

Do I have to sign up for the trial?

No. Every new machine starts with 30 days of Pro, with no sign-up and no card.

What happens when the 30-day trial ends?

The machine goes back to Free. The editors and everything on the Free list keep working, and a Pro feature asks you to buy when you reach it. Nothing is deleted. See what happens when the trial ends.

Can I restart the trial by reinstalling?

No. The trial is per machine and its start date is kept by the licence service, so a reinstall does not give a new one.

Can I get a refund?

Yes. Your first payment is refunded in full on request within {{config:refund.firstPaymentDays}} days, and a renewal within {{config:refund.renewalDays}} days. Write to {{contact}}. Polar processes the refund.

Do students, teachers and open-source maintainers pay?

They can get Pro for free. Write to {{contact}} and say which group you are in. See Buying and signing in.

I used Camunda BPMN Editor. Did I lose anything?

Almost nothing. One feature moved: the side-by-side diagram view in the IDE's compare window is part of Pro now. See the details.

Data and safety

Does Penstock send my diagrams anywhere?

No. A diagram goes only to the engine you configure when you deploy, and to the AI agent you choose if you use the AI chat. There is no telemetry. See Security and privacy.

What does the licence service receive?

The licence, a one-way hash of the machine's id and the host name as a label, plus the address a request comes from. Never a diagram. See the privacy policy.

Does it work offline?

Mostly. Deploying, engine questions, connector downloads and licence checks need a connection. A valid licence token keeps working for up to 30 days offline.

Where do my passwords go?

To the secret store of your tool, once for each profile. Never to a project file.

Tools and engines

Which tools can I use?

JetBrains IDEs from 2023.1, VS Code 1.88 or later, and a command line that needs {{node}}. See Install.

Which engines work?

Camunda 7, Camunda 8, Operaton, CIB seven and plain BPMN 2.0.

Can I keep using Camunda Modeler?

Yes. Both edit the same files.

Does Penstock include an AI model?

No. The AI chat starts the agent you choose, on your own account.
