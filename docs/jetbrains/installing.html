Installing

How to put Penstock into your JetBrains IDE, and how to check that it works.

Free Any JetBrains IDE from 2025.2

What you need

An IDEAny JetBrains IDE from version 2025.2. IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider and the others all work.
JCEFThe web view the editor is drawn in. The normal IDE downloads have it. If you use a custom runtime without it, see Troubleshooting.
The Marketplace namePenstock, plugin id 25710. Until 2026 it was called Camunda BPMN Editor. It is the same plugin, so an old install updates in place.
The priceFree. Every new machine also gets 30 days of Pro. See Plans and licence.

Install the plugin

  1. Open Settings | Plugins. On macOS that is Settings in the IDE menu, or press Cmd+,.
  2. Open the Marketplace tab and search for Penstock.
  3. Press Install.
  4. Press Restart IDE when the IDE asks.
  5. Open any .bpmn file. It opens in the diagram editor.

You can also install it from the Marketplace page in a browser. Press Install to IDE there.

What you see

  • The file opens as a picture of the process, with a toolbar on top and a properties panel on the right.
  • Two tabs sit at the bottom of the editor: BPMN Editor and Text. The second one is the raw XML. Both edit the same file.
  • A new tool window called Penstock appears on the left. It lists every diagram, decision and form in the project.
  • The first time you open the editor, a short tour of six steps points out the palette, the properties panel, Check, the tool window, Deploy and the More menu. It is shown once. To see it again, open More and choose Show the tour again.

Two builds, one plugin

Every release ships two builds from the same source. One is for IDEs 2025.2 to 2026.1. The other is for 2026.2 and later. The Marketplace serves the right one for your IDE. You do nothing.

Versions are numbered by the calendar: 26.9.0 means year 26, month 9, release 0. The build for the older IDEs has -252 after the number and the other has -262. The command line has the bare number.

Update

The IDE updates the plugin like any other. After an update, Penstock shows one notification that names the new version. It has a What's new button that opens the changelog in an editor tab. Nothing is shown after a fresh install.

The full history is in CHANGELOG.md.

Uninstall

  1. Open Settings | Plugins and the Installed tab.
  2. Choose Penstock and press Uninstall.
  3. Restart the IDE.

Your diagrams are ordinary files, so they stay exactly as they are. Penstock keeps a few small files of its own on your machine. To remove them all, delete the folder ~/.penstock. Files Penstock reads and writes lists each one.

The command line is separate

The plugin does not install the penstock command. The command line needs Node.js 20.19 or later. It is installed per project, through a small script that pins the version. See Command line.

Common problems

The editor is blank or shows only the XML.
Check that the IDE is 2025.2 or newer and that it has JCEF. Then read Troubleshooting.
I cannot find Penstock in the Marketplace.
Search for "Penstock". If you still have "Camunda BPMN Editor" installed, it is the same plugin. Update it and it becomes Penstock.
The IDE says the plugin is not compatible.
Your IDE is older than 2025.2. Update the IDE first.
A .bpmn file opens as plain XML only.
Use the tabs at the bottom of the editor to switch to BPMN Editor. If there is no such tab, the plugin is disabled. Turn it on in Settings | Plugins.
