JetBrains IDEs

Penstock runs inside IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider and the other JetBrains IDEs from 2024.2, and adds the editors, the checks and a project tool window to them.

Every feature of Penstock is described once, for every tool, in the Guide. This section only says what is special about the IDE: how to install it, where things are, and the features that need an IDE, such as clicking from code to a diagram.

Start here

  1. Install the plugin from the JetBrains Marketplace. It is free and takes two minutes.
  2. Open a .bpmn file. See The editor in the IDE.
  3. Read Where things are in the IDE, and the Penstock tool window.
  4. Then follow Getting started in the Guide.

Start here

InstallingPut Penstock into your IDE and check that it works. Where things are in the IDEEvery place Penstock shows up: toolbar, tool window, menus, gutter.

Using it

The editor in the IDEFile types, the two tabs, saving, themes, and files changed outside. The Penstock tool windowYour project as a tree, and the Run Penstock menu. Code links in the IDEClick through, completion, gutter icons, Code Vision, Find Usages, the debugger. Rename in the IDEOne rename for a job type, topic, class, bean, message or process, in diagrams and code. Tests in the IDETest-case files in the test runner, gutter icons, process tests, coverage. ShortcutsKeys that work in the editor and in the code. Settings in the IDEThe Penstock settings page, inspections, keymap, run configuration and notifications.

Licence and help

Licence in the IDEThe status bar, the Tools menu and the licence dialog. TroubleshootingA blank editor, files that open as text, the tool window.

What is only in the IDE

  • The Penstock page in Settings, the inspections, the keymap and the notifications: Settings in the IDE.
  • Clicking from a string in your code to a diagram element, completion of ids, gutter icons, Code Vision and Find Usages: Code links in the IDE.
  • Test-case files in the IDE test runner, and running process tests from a diagram: Tests in the IDE.
  • Editing a script in a real code editor tab: Scripts in their own tab.
  • The visual diagram diff in the IDE's diff window: Diagram diff.
