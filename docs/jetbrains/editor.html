The editor in the IDE

How the BPMN, DMN and form editors sit inside a JetBrains IDE: which files open, the two tabs, saving and files changed outside.

This page is only about the IDE. What the editor does is described once, for every tool, in The BPMN editor, The DMN editor and The form editor.

Which files open in the editor

File type in the IDEExtensionsOpens in
BPMNbpmn, bpmn.xml, bpmn20.xmlThe BPMN editor
DMNdmnThe DMN editor
Camunda Formform, when the file is a Camunda Form (a JSON object with components)The form editor

A .form file from the IntelliJ GUI Designer is left to the GUI Designer. Penstock takes only Camunda Forms.

The two tabs

The editor is registered ahead of the IDE's own editor, not in place of it. So a file has two tabs at the foot of the editor window:

  • BPMN Editor (or DMN Editor, Form Editor) shows the picture.
  • Text shows the raw XML or JSON in the IDE's own text editor.

Both edit the same file. A change on the canvas shows in the Text tab at once.

Saving

The editor writes the file on every change. The content goes to a temporary file that replaces the real one, and the IDE refreshes the file, so the Text tab and version control see it immediately.

When the file changes outside the editor

The IDE tells Penstock when a file changes on disk. A dialog called File Changed on Disk asks Reload or Keep Editing. Renaming or moving the open file is followed without asking. The editor's own saves are never mistaken for outside changes.

Themes

The diagram takes the IDE's theme: light, dark or Dracula. A change of IDE theme redraws the diagram. Sketchy drawing is a personal choice in the More menu.

Clipboard

Copy and paste use the IDE's clipboard, so you can copy a pool from one diagram and paste it into a diagram open in another tab. Copy as image puts a PNG on the IDE clipboard, ready to paste into Confluence, Slack or an e-mail.

The context menu

Right-click an element for the editing actions, and, when they apply, Go to the Java class a task names, and the Pro actions that link to your code. See Code links in the IDE.

Common problems

A .bpmn file opens as plain XML only.
Click the BPMN Editor tab at the bottom of the editor. If there is no such tab, the plugin is disabled. Turn it on in Settings | Plugins. If the file still opens as text, the pattern may have been given to another file type in Settings | Editor | File Types. Move it back to BPMN.
A .form file opens in the GUI Designer.
It is a GUI Designer form, not a Camunda Form.
The editor is blank.
See Troubleshooting.
