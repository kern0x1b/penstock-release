Install Penstock

Pick your tool. It is the same editor, the same licence and the same 30-day Pro trial in all of them, with nothing to sign up for.

Penstock was published as Camunda BPMN Editor until 2026. It is the same plugin, and it updates in place, so nothing needs to be reinstalled.

JetBrains | VS Code | Command line

JetBrains IDEs

Any JetBrains IDE from 2023.1 with JCEF, which the standard downloads include: IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider and the rest.

Install from the JetBrains Marketplace
  1. Open Settings | Plugins | Marketplace.
  2. Search for Penstock and press Install.
  3. Open any .bpmn file. It opens in the visual editor, with the XML one tab away.
  4. The status bar shows the trial and the days left.

The Marketplace picks the build that fits your IDE. If you used to search for Camunda BPMN Editor, this is the same plugin. More in Installing in JetBrains and the quick start.

VS Code

VS Code 1.88 or later.

Install from the Visual Studio Marketplace
code --install-extension penstock.penstock
  • Open a .bpmn file. It opens in the Penstock editor.
  • The Penstock view in the Activity Bar shows the project as a tree.

Cursor, Windsurf, VSCodium and other forks, or no access to the Marketplace

Editors built on VS Code take extensions from their own registry, usually Open VSX, and not from Microsoft's Marketplace. Where the extension cannot be found, install it from a .vsix file: Install from VSIX... in the Extensions view, or code --install-extension penstock.vsix. See Install from a VSIX file.

More in Installing in VS Code and the quick start.

The package is on npm. penstock doctor says what is wrong with a project. The command line is separate from the editors, and it shares their licence: one licence covers the JetBrains plugin, the VS Code extension and the command line. More in Command line and the quick start.

Your first ten minutes

  1. Write the example project into an empty folder. In a terminal: penstock init --example camunda-8 (or camunda-7). The editors offer it too, in the Penstock view.
  2. Open order-process.bpmn and press Check.
  3. Press Deploy to deploy it to an engine.

Getting started takes you from nothing installed to a checked, deployed process in about ten minutes.

What is free

The editors, the check and lint, deploy, Monitor, token simulation, export, share and import are free, with no time limit. Every new machine also starts with 30 days of Pro. See pricing.

Uninstall and your data

Uninstalling removes the plugin or extension. Your diagrams are your own files and stay in your project. Penstock keeps its preferences and licence in ~/.penstock and secrets in your tool's secret store. See Files Penstock writes.
