Install it in your tool

The features, the licence and the trial are the same in all three.

JetBrains IDEsAny JetBrains IDE from 2023.1. Open Settings | Plugins | Marketplace, search for Penstock and press Install. Quick start.
VS CodeRun code --install-extension penstock.penstock, or press Install on the Marketplace page. Quick start.
Command lineRun npm install -g @kern0x1b/penstock-cli, or try it once with npx @kern0x1b/penstock-cli. It needs Node.js 22.22.2 or later in 22, 24.15.0 or later in 24, or 26 and later. Quick start.

Then follow Get started: from nothing installed to a checked, deployed process in about ten minutes. All install options.

Questions

What happened to Camunda BPMN Editor?

It was renamed Penstock in 2026. It is the same plugin from the same author, so it updates in place and nothing needs to be reinstalled.

Is it really free?

Yes, with no time limit. The editors, check, deploy, Monitor, token simulation, export and import are free. Pro and Team are optional.

What happens after the 30-day trial?

The machine goes back to Free. Nothing is deleted, and a Pro feature asks you to buy when you reach it.

Does it send my diagrams anywhere?

No. A diagram goes only to the engine you deploy to, and to the AI agent you choose if you use the AI chat. There is no telemetry.
