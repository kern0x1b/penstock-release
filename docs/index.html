Edit, check and deploy BPMN diagrams where you already work.

Penstock is a visual editor for BPMN, DMN and Camunda forms, for Camunda 7, Camunda 8, Operaton and CIB seven. It runs in JetBrains IDEs and in VS Code, and a command line runs the same checks in your pipeline. Diagrams stay in your project, next to the code.

Install it in your tool

The features, the licence and the trial are the same in all three.

JetBrains IDEsAny JetBrains IDE from 2024.2. Open Settings | Plugins | Marketplace, search for Penstock and press Install. More on installing.
VS CodeRun code --install-extension penstock.penstock, or press Install on the Marketplace page. More on installing.
Command lineRun npm install -g @kern0x1b/penstock-cli, or try it once with npx @kern0x1b/penstock-cli. It needs Node.js 22.22.2 or later in 22, 24.15.0 or later in 24, or 26 and later. More on the command line.

Then follow Get started: from nothing installed to a checked, deployed process in about ten minutes.

From drawing to running

One guide, written once. It describes the same editor in every tool.

Draw and editVisual editors for BPMN, DMN and forms, with a properties panel for each engine. Every change is written to the file at once. Check your workDrawing problems, bpmnlint rules and, with Pro, how the process runs and where it can get stuck. Test and runPlan every way through a process, run the test cases on a local engine, deploy in one click and watch the instances. Link diagrams and codeJump from a task to the worker that runs it, and back. Find the tasks nothing implements. Share and moveOne offline HTML file to send. Import from draw.io, Visio, Signavio and Bizagi. Convert Camunda 7 to Camunda 8. In your pipelineThe same checks from a terminal or a pull request, and an MCP server for AI assistants.

Free, Pro and Team

Everything a modeller needs is free: the editors, the properties panels, the command palette, the sidebar, templates, token simulation, the check and its lint, deploy, Monitor, export, share and import.

Pro adds what only Penstock does: auto layout, flow analysis, code links, scenarios, the visual diagram diff, converting Camunda 7 to Camunda 8 and more. One rule decides which plan a feature needs: Pro on your machine, Team in a pipeline.

Every machine starts with 30 days of Pro. The licence is a signed token that the plugin, the extension and the command line check offline.
