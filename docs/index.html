BPMN diagrams, in the tools you already use.

Penstock edits BPMN, DMN and forms for Camunda 7, Camunda 8, Operaton and CIB seven, next to the raw XML. Diagrams stay in your project and in version control, so they are reviewed like code. It runs inside JetBrains IDEs, and a penstock command does the same checks in a pipeline.

Start in five minutes

  1. Get Penstock. In a JetBrains IDE, install the plugin from the Marketplace (Installing). On the command line, run npx @penstock/cli (Command line).
  2. Open a .bpmn file. It opens in the diagram editor, and the XML is one tab away.
  3. Or try the example. Write it into an empty folder. See The example project.
  4. Press Check. It lists what is wrong and how to fix it.
  5. Press Deploy. Give it your engine address once.
