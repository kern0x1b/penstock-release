Defaults for new elements

convention/defaults · Modelling conventions · Off by default

Why it matters

Attributes every service task or data input of a project needs, set once, are never forgotten on one of them.

How to fix it

Set them under conventions.defaults in penstock.yaml, keyed by BPMN type such as bpmn:ServiceTask.
