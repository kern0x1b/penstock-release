Guide / Every rule

Connection runs through a shape

The check drawing/edge-through-node, in the group Drawing.

Error

Why it matters

A connection drawn through a shape it does not touch looks like it connects to that shape.

How to fix it

Move a bend of the connection, or the shape, so the line goes around.

Where you see it

The Problems tab lists it under Problems, and outlines the element on the canvas. In a terminal, penstock check --only drawing reports it as EDGE-THROUGH-NODE. Auto layout often fixes it for the whole diagram at once.

Rule details

Iddrawing/edge-through-node
GroupDrawing
LevelError: the diagram or the process is wrong
Name in penstock checkEDGE-THROUGH-NODE
