Nothing in the code throws the error a step catches

code/never-thrown · Diagrams and code · Advice: it works, and reads or runs better without it

Why it matters

An error boundary or error event catches a code that no BpmnError or error command in the project throws, so it never fires.

How to fix it

Throw the error code from the worker, or correct the code on the event.
