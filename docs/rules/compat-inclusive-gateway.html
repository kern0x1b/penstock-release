Inclusive gateway with more than one way in

compat/inclusive-gateway · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

Camunda 8 before 8.6 can take an inclusive gateway only as a fork, so one that also joins is refused.

How to fix it

Use one gateway to fork and another to join, or raise the platform version of the diagram.

In penstock check and in the editor the rule is called compat/inclusive-gateway. In .bpmnlintrc it is turned off as camunda-compat/inclusive-gateway or as compat/inclusive-gateway.
