Only part of the process was analysed

flow/too-complex · Process flow · Advice: it works, and reads or runs better without it

Why it matters

The process has too many states to check them all, so what the check says is true only of the part it reached.

How to fix it

Split the process into sub-processes or call activities so each can be checked whole.

In penstock check and in the editor the rule is called TOO-COMPLEX.
