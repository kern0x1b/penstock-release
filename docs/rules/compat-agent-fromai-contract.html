fromAi() key that is not a plain name under toolCall

compat/agent-fromai-contract · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

The agent fills a tool parameter through fromAi(toolCall.name); a key written any other way is not found, so the parameter stays empty.

How to fix it

Write the key as toolCall.name: a single name, with dots, and no quotes, brackets or arithmetic.

In penstock check and in the editor the rule is called compat/agent-fromai-contract. In .bpmnlintrc it is turned off as camunda-compat/agent-fromai-contract or as compat/agent-fromai-contract.
