The process can get stuck

flow/deadlock · Process flow · Error: the diagram or the process is wrong

Why it matters

A token can reach a point where nothing can move it on, so the instance never ends and sits in the engine forever.

How to fix it

Follow the path shown in the finding and give the stuck join a way to continue, for example by joining only what was split.

In penstock check and in the editor the rule is called DEADLOCK.
