Ad-hoc sub-process without an activity

compat/ad-hoc-sub-process · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

An ad-hoc sub-process with nothing in it has nothing for the engine to run, so the instance can never complete it.

How to fix it

Add at least one activity to the ad-hoc sub-process, or delete it.

In penstock check and in the editor the rule is called compat/ad-hoc-sub-process. In .bpmnlintrc it is turned off as camunda-compat/ad-hoc-sub-process or as compat/ad-hoc-sub-process.
