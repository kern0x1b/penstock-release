Two identical flows between the same elements

bpmnlint/no-duplicate-sequence-flows · Modelling rules · Error: the diagram or the process is wrong

Why it matters

Two flows from the same source to the same target either do the same twice or say nothing the first one did not.

How to fix it

Delete the duplicate flow.

In penstock check and in the editor the rule is called bpmnlint/no-duplicate-sequence-flows.
