Annotation sits far from what it describes

The check drawing/note-adrift, in the group Drawing.

Advice

On this page

  • Why it matters
  • How to fix it
  • Where you see it
  • Rule details

Why it matters

An annotation far from its element is hard to tie to it.

How to fix it

Drag the annotation next to the element it describes.

Where you see it

The check card lists it under Readability, and outlines the element on the canvas. In a terminal, penstock check --only drawing reports it as NOTE-ADRIFT. Auto layout often fixes it for the whole diagram at once.

GroupDrawing
LevelAdvice: it works, and reads or runs better without it
