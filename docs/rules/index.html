How to read a rule page

Every check Penstock makes has a page. It says why it matters, how to fix it, and where you see it. In the diagram check, select a finding and its link opens the page. In penstock check --format json, SARIF and GitHub annotations, every finding carries the rule id and the address of its page.

LevelMeaning
ErrorThe diagram or the process is wrong. penstock check fails on it.
AdviceIt works, and reads or runs better without it. It is shown as a note and does not fail the check.
Off by defaultThe rule exists but does nothing until you turn it on.

78 rules in 7 groups. The groups: modelling rules (bpmnlint), drawing, process flow, decision tables, forms, diagrams and code and modelling conventions. Process flow, decision tables, forms and diagrams and code are part of Pro.
