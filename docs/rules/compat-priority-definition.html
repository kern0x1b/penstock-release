User task priority that is not valid

compat/priority-definition · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

The priority of a user task has to be a whole number from 0 to 100, or an expression; anything else is refused.

How to fix it

Write the priority as a number from 0 to 100, or as an expression.

In penstock check and in the editor the rule is called compat/priority-definition. In .bpmnlintrc it is turned off as camunda-compat/priority-definition or as compat/priority-definition.
