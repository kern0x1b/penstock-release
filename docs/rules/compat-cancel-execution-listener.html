cancel listener on an element that cannot be cancelled

compat/cancel-execution-listener · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

A cancel execution listener runs when an element is terminated, which only some elements can be, so on the others it never fires.

How to fix it

Use the listener on an element that supports it, or give it another event type.

In penstock check and in the editor the rule is called compat/cancel-execution-listener. In .bpmnlintrc it is turned off as camunda-compat/cancel-execution-listener or as compat/cancel-execution-listener.
