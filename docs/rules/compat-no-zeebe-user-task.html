Camunda user task that this version does not have

compat/no-zeebe-user-task · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

A user task implemented by Camunda itself needs Camunda 8.5 or newer.

How to fix it

Use a job worker user task, or raise the platform version of the diagram.

In penstock check and in the editor the rule is called compat/no-zeebe-user-task. In .bpmnlintrc it is turned off as camunda-compat/no-zeebe-user-task or as compat/no-zeebe-user-task.
