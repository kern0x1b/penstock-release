User task form that is not filled in

compat/user-task-form · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

A form on a user task needs the form id, or the linked form, in the form the chosen binding expects; without it the task opens with no form.

How to fix it

Set the form id, or the form key, the way its binding says.

In penstock check and in the editor the rule is called compat/user-task-form. In .bpmnlintrc it is turned off as camunda-compat/user-task-form or as compat/user-task-form.
