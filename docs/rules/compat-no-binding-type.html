Binding type that this version does not have

compat/no-binding-type · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

A called process, decision or form bound to anything but the latest version needs Camunda 8.6 or newer; on an older one the binding is ignored.

How to fix it

Bind to the latest version, or raise the platform version of the diagram.

In penstock check and in the editor the rule is called compat/no-binding-type. In .bpmnlintrc it is turned off as camunda-compat/no-binding-type or as compat/no-binding-type.
