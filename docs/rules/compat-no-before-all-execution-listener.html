beforeAll listener that this version does not have

compat/no-before-all-execution-listener · Engine compatibility · Error: the diagram or the process is wrong

Why it matters

The beforeAll event type of an execution listener needs Camunda 8.10 or newer.

How to fix it

Use another event type, or raise the platform version of the diagram.

In penstock check and in the editor the rule is called compat/no-before-all-execution-listener. In .bpmnlintrc it is turned off as camunda-compat/no-before-all-execution-listener or as compat/no-before-all-execution-listener.
