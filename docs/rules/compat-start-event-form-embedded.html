Embedded form on a start event

compat/start-event-form-embedded · Engine compatibility · Advice: it works, and reads or runs better without it

Why it matters

Embedded forms on a start event are deprecated in this version and stop working in a later one.

How to fix it

Move the form to a .form file and link it from the start event.

In penstock check and in the editor the rule is called compat/start-event-form-embedded. In .bpmnlintrc it is turned off as camunda-compat/start-event-form-embedded or as compat/start-event-form-embedded.
