An element can never run

flow/dead-element · Process flow · Error: the diagram or the process is wrong

Why it matters

No path from the start reaches the element, so whatever it does is dead weight in the diagram.

How to fix it

Connect it to a path that can reach it, or delete it.

In penstock check and in the editor the rule is called DEAD-ELEMENT.
