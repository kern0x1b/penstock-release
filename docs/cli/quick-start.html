Quick start on the command line

From nothing installed to a checked, deployed process in a terminal, on one screen.

Free Node.js 22.22.2 or later in 22, 24.15.0 or later in 24, or 26 and later

  1. Install. Run npm install -g @kern0x1b/penstock-cli, or prefix every command below with npx @kern0x1b/penstock-cli to run it once. The package is on npm.
  2. Write the example. In an empty folder run penstock init --example camunda-8, or --example camunda-7. It writes the files and the penstockw wrapper.
  3. Check it. Run penstock check .. It lists what is wrong. A fresh example has nothing wrong.
  4. See what a deploy would do. Run penstock deploy . --dry-run. It prints a table with a row for each engine and file.
  5. Deploy it. Run penstock deploy . with an engine running.
penstock init --example camunda-8
penstock check .
penstock deploy . --dry-run
penstock deploy .

What you should see

  • penstock doctor says which settings apply, and what is wrong with the project.
  • penstock license says which licence the machine has. Every new machine starts with 30 days of Pro.
