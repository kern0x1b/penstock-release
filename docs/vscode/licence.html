Licence in VS Code

Where to see and change your licence in VS Code: the status bar, the account dialog, the Command Palette and the message that explains a paid feature.

How the trial, buying, signing in and machines work is described once in Buying and signing in. This page is about VS Code.

One licence for every tool

The extension reads the licence from ~/.penstock, the folder the JetBrains plugin and the command line use. So a licence bought or a trial started in one tool is the licence in the others, and signing in once on a machine is enough.

The status bar

The right end of the status bar shows the licence: Penstock Pro trial: 27d while the trial runs, Penstock Free when it ends, and Penstock Pro or Penstock Team once you have a licence. Hover it for the detail. Click it to open the account dialog. In the list of status bar items it is called Penstock Licence.

The account dialog

Open it by clicking the status bar item, or run Penstock: Licence and account in the Command Palette.

Without a licenceA dialog that names the plan, for example Penstock Free, and has the buttons Buy Pro, Buy Team and Sign in.
With a licenceThe plan and its detail, and the buttons Buy Team (from Pro), Copy key for CI and Release this machine.

Buy

  1. Open the account dialog and press Buy Pro or Buy Team.
  2. The checkout opens in your browser. Pay there.
  3. VS Code notices the payment by itself. It stops waiting after an hour. If you paid after that, sign in with the address you paid with.
  4. It then asks for the code sent to your e-mail. Type it in and the licence is active on this machine.

Sign in

  1. Run Penstock: Sign in, or press Sign in in the account dialog.
  2. Type the e-mail you bought Penstock with, or a licence key that starts with PENSTOCK-, in the box E-mail or licence key.
  3. For an e-mail, type the code that is sent to it. After three wrong codes, the attempt ends.

Copy the key for a pipeline

The machine does not keep the key. Copy key for CI asks for the e-mail code again and finds the Team key. The key is put on the clipboard. Keep it secret, and in a pipeline set it as PENSTOCK_LICENSE. Only a Team key works in a pipeline. VS Code itself has no pipeline, so there is no Team tier in the extension. See Buying and signing in.

Machines

When the licence is in use on as many machines as it allows, signing in lists them with the time each was activated. Pick one to free for this machine. Release this machine frees this one for use elsewhere. If there is no seat on this machine, the licence file is cleared and VS Code says so.

The message that explains a paid feature

When you use a paid feature without the licence, a message says, for example, Auto layout is part of Penstock Pro and what the feature does. If the trial has ended, it says that too. It offers to buy, or to sign in if you already bought. The paid features are auto layout, modelling conventions, flow analysis, process test runs, the visual diagram diff, the code links and sending a message in the AI chat. The input and the chats are shown to everyone, and the offer comes when you send.

Common problems

The status bar shows nothing about Penstock.
The item is hidden when the licence cannot be read. It may also be hidden in the status bar menu: right-click the status bar and turn on Penstock Licence.
I signed in on the command line but VS Code still shows the trial.
They share ~/.penstock/license.json. Open the account dialog to see what VS Code found.
"The licence service could not be reached."
Penstock could not reach the licence service. Check the network, then try again.
"There is no Penstock licence bought with" an address.
The address is not the one you paid with. Sign in with that address, or buy a licence.
