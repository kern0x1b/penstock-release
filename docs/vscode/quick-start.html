Quick start in VS Code

From nothing installed to a checked, deployed process in VS Code, on one screen.

Free VS Code 1.88 or later

  1. Install. Run code --install-extension penstock.penstock in a terminal, or open the Marketplace page and press Install. In Cursor, Windsurf and VSCodium, install from a VSIX file if the extension is not in their registry.
  2. Write the example. Open an empty folder and open the Penstock view in the Activity Bar. Choose Camunda 8 order process or Camunda 7 order process. Or open a .bpmn file of your own.
  3. Open the diagram. Double-click order-process.bpmn in the Explorer. It opens in the Penstock editor. Penstock: Open as text opens the XML beside it.
  4. Check it. Press Check on the editor's toolbar. A card lists what is wrong. A fresh example has nothing wrong.
  5. Deploy it. Press Deploy. The first time, it asks for the engine address. Enter it, save, and deploy again.

What you should see

  • The diagram in the editor, with the palette on the left and the properties of the selected element on the right.
  • The licence status in the status bar: every new machine starts with 30 days of Pro. Penstock: Licence and account in the Command Palette shows it.
  • After Deploy, the process on your engine. The Monitor tab shows its instances.
