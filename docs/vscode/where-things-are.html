The map

WhereWhat is there
The editor of a .bpmn, .bpmn20.xml, .dmn or .form fileA custom editor, called Penstock BPMN Editor, Penstock DMN Editor or Penstock Form Editor. It opens in place of the text when you open the file. See The BPMN editor.
The toolbar of the editorAuto layout, Check, Simulate, Monitor, Scenarios, the More menu, Deploy and the sidebar toggle. See Toolbar and More menu.
The sidebar of the editorThe column beside the canvas, with the tabs Properties, Scenarios, Problems, Comments, Monitor and Code. These are the editor's own tabs, not VS Code's. See The sidebar.
The More menu of the editorA searchable list of every action, in the editor. See Toolbar and More menu.
The Command Palette, under PenstockEvery action of the editor as a command with the name it has in the editor: Auto layout, Check, Deploy, Export…, Share as HTML… and the rest. Also Penstock: Find action, Penstock: Open as text, Penstock: Compare with…, Penstock: Licence and account and Penstock: Sign in. See below.
The Command Palette: Open documentationOpens this guide in your browser.
The Activity Bar view container PenstockThe Penstock tool window: processes, workers, variables, messages, errors, decisions, forms, templates, deployment, files, and Migrate to Camunda 8. The toolbar has Run all, reload, group by file, folders, Open penstock.yaml, and a Run Penstock menu with 9 CLI commands. Row menus offer Open, Find usages in code, Copy ID, Go to implementation, Deploy, test actions, and CLI commands on the row's file. Pro. See Code links in VS Code.
The Problems viewWhat penstock code reports: a step nothing runs, a worker no diagram uses, a name that is a letter or a case away from a known one. Pro. The findings of the Check card stay in the editor. See Diagram check.
Above a worker, delegate or subscription in your codeA code lens that names the diagram and element that use it. Pro. See Code links in VS Code.
The Test ExplorerA controller called Penstock scenarios, with one node per diagram and one per test case. Pro. See Scenarios.
The Output panelA channel called Penstock Test Runs, with the steps and the trace of a test run.

The status bar, right sideThe licence: Penstock Free, Penstock Pro trial: 27d, Penstock Pro or Penstock Team. Click it for the account dialog. See Licence in VS Code.
VS Code's SettingsNothing of Penstock's own. The extension contributes no settings. The project is set up in penstock.yaml. See penstock.yaml.

Text and diagram

The text document is the only history of a diagram. An edit on the canvas changes the document, and an edit in a text editor beside it changes the canvas. Undo, Redo, Revert and git all act on that document. A file that changes on disk reaches the canvas.

To read the XML, run Penstock: Open as text while the editor has focus. The file opens in VS Code's text editor beside the diagram and is remembered as one you opened as text, so Penstock does not switch it back to the diagram when VS Code starts.

The Command Palette

  • An action that the open diagram does not offer is not in the palette. An action it has switched off is greyed out.
  • The commands are enabled while a Penstock editor has focus. If one is run with no editor open, VS Code says to open a Penstock editor to use it. If the diagram does not offer it, VS Code says the action is not available for this diagram.
  • Penstock: Find action opens the editor's own searchable list.

What you see

  • The editor keeps the layout, spacing, type and icons it has in the JetBrains IDE. Only the colours come from the VS Code theme, so a switch between Dark Modern, Light Modern, the high contrast themes or any theme you installed repaints it without a reload.
  • Dialogs put the main button on the right on a Mac and on the left everywhere else.
  • The text of the editor shell follows the language of the VS Code window.

Common problems

I cannot find a feature.
Check the table above. Some actions are only in the More menu of the editor or in the Command Palette. A few are not available in VS Code yet. See VS Code.
There is no Penstock page in Settings.
Right. The project is set up in penstock.yaml, and the personal choices are in ~/.penstock/preferences.json.
