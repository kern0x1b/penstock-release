VS Code

Penstock is a VS Code extension. BPMN, DMN and form files open in the Penstock editor, and the project, the deployment, the licence and the links to your code work as they do in the JetBrains plugin.

Every feature of Penstock is described once, for every tool, in the Guide. This section only says what is special about VS Code: how to install it, where things are, and what is not there yet.

Start here

  1. Install the extension from the Visual Studio Marketplace. It needs VS Code 1.88 or later.
  2. Open a .bpmn, .dmn or .form file. It opens in the Penstock editor.
  3. Read Where things are in VS Code.
  4. Then follow Getting started in the Guide.

What works

  • The BPMN, DMN and form editors, with the toolbar, the palette, the properties panel and the sidebar. The text document is the only history, so VS Code's own Undo, Redo, Revert and git all work on a diagram.
  • penstock.yaml, its layers per folder, penstock.local.yaml, profiles and ${VAR} references.
  • Deployment to Camunda 7 and Camunda 8, with passwords and client secrets kept in VS Code's secret storage.
  • Scripts in their own tab, element templates, and the Check, Simulate, Monitor and Scenarios actions of the editor.
  • Test-case files in the Test Explorer, with a Pro licence.
  • The visual diagram diff, from the Explorer and Source Control menus, with a Pro licence.
  • Code links: code lenses, go to definition and references between diagrams and code, a Code view and Problems, with a Pro licence.
  • The licence, shared with the plugin and the command line. See Licence in VS Code.
  • Every action of the editor as a command in the Command Palette, under Penstock.
  • Your VS Code theme: the editor keeps its own layout and type and takes only its colour from the theme.

What is not there yet

  • The Camunda 7 to Camunda 8 conversion preview, and the conversion itself.
  • Running the tests a diagram is linked to, from the diagram, and the debugger's position on the diagram.
  • Renaming a job type, topic, class or message in diagrams and code in one step.
  • Putting a picture on the clipboard. A picture can still be exported to a file.
  • The project tree of the JetBrains tool window and its Run Penstock actions. The Code view in the Explorer holds the code sections of that tree. Whole-project commands are in the command line.
  • A pipeline. There is no pipeline in VS Code, so there is no Team tier here. The command line runs in a pipeline.

A feature that is missing says "not available in VS Code yet" when you reach for it. See Troubleshooting.

Pick your tool
