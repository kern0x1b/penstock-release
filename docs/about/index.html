About Penstock

Penstock is an editor for BPMN, DMN and Camunda forms that lives inside your IDE. It is made by one person.

Who makes it

Penstock is made by Oleksandr Havrysh, an individual in Poland. It started as a JetBrains plugin called Camunda BPMN Editor. In 2026 it was renamed Penstock, and it grew into a family of tools for JetBrains IDEs, VS Code and the command line that share one licence.

Independent of Camunda

Penstock is an independent product. It is not affiliated with, endorsed by, or sponsored by Camunda Services GmbH. Camunda is a trademark of Camunda Services GmbH. BPMN is a trademark of the Object Management Group. The names are used only to say which engines and which notation Penstock works with.

History

  • Releases up to 2.4.0 were published as Camunda BPMN Editor under the MIT licence.
  • Release 2.4.1, on 31 August 2026, renamed the plugin to Penstock, with the same plugin ID, and moved it to the end user licence.
  • Release 26.9.0, on 25 September 2026, switched to calendar version numbers and made the product free, with Pro and Team plans for what only Penstock does.
