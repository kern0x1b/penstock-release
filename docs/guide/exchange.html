Sharing and importing

Two ways a diagram gets in or out of Penstock without the project: send somebody one HTML file they can open in a browser, and bring in a diagram drawn in another tool. Both are free.

Share as HTML

Share as HTML… is in the More menu of the diagram, decision and form editors, and is penstock share <file> in a terminal. It writes one HTML file that opens offline in any browser.

A diagram is a read-only viewer: zoom and pan, the documentation of an element when you click it, and the diagram's name at the top. The page follows the reader's own light or dark setting, and carries a small Made with Penstock footer. The bpmn.io watermark stays visible in the corner, as its licence asks.

A .dmn file is shared as its tables, and a .form as its fields, so a decision or a form can be sent on its own.

The file loads nothing and sends nothing. There is no network request in it, no content delivery network, no analytics, and a content security policy that forbids all three. It works from a file system, an email attachment or a file share.

penstock share orders.bpmn -o orders.html

Without -o the file is written next to the diagram, named after it. This is different from Export, which draws the diagram for a document or a wiki, and from penstock docs, which writes a page of prose about every process.

Import diagram

Import diagram… is in the More menu, and is penstock import <file> in a terminal. It turns a diagram drawn in another tool into BPMN 2.0, which you then open and edit as a Penstock diagram.

draw.io.drawio, .xml, compressed or not
Visio.vsdx
Signavio.bpmn
Bizagi.bpmn

What is mapped

Tasks and the kinds of task, events and their triggers, boundary events, gateways, sub-processes, pools, lanes, sequence flows, message flows and default flows, text annotations and data objects. The positions of the shapes are kept, and so are the bends of the connectors, so the imported diagram looks like the one you drew.

What is not

Anything that has no meaning in BPMN, anything that had to be read by how it looks, and anything BPMN has nowhere to put, is listed in the import report rather than dropped quietly. The report is a dialog in the editor and lines in the terminal, and its heading leads with the count: 3 not imported. What could not be mapped is in the warning colour; the red is kept for a file that could not be read at all. A connector route that was drawn rather than routed is reported as drawn - Auto layout can lay it out afterwards, which is Pro.

What cannot be read

A Bizagi .bpm package and the old binary Visio .vsd cannot be read. The message says what to export from the tool instead, rather than only saying no.

penstock import diagram.drawio -o process.bpmn

Nothing is written if the file already exists, unless you pass --force or name another output with -o. A file that could not be read writes nothing at all.

Both in a pipeline

penstock share and penstock import are free and need no licence, so either can run in CI: share a diagram as an HTML page in a release, or convert a draw.io file kept in the repository into a BPMN file before the check runs. See Command line.
