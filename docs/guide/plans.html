The one rule

Everything that earlier releases had, and everything other tools give away, is free. What only Penstock does is Pro or Team.

A paid feature needs Pro on your own machine and Team inside a pipeline. A pipeline is any run where the environment variable CI is set. There are no exceptions for a single feature or a single flag.

Every machine starts with 30 days of Pro. A pipeline gets no trial.

Not sure what a page needs? The tag under its title says. Free means free. Pro means a paid feature.

What you see when you reach a paid feature

Nothing else in the editor changes. When you reach for a paid feature you do not have, Penstock explains what it does and offers to buy it or to sign in, at that moment.

  • In an editor, a dialog says, for example, Auto layout is part of Penstock Pro. and offers Buy Pro, I Already Bought It and Not Now. If your trial has ended it says so.
  • In a terminal, the command prints what the feature gives and the commands penstock license buy and penstock license login. In a pipeline it says the feature needs Team and to give the pipeline a key in PENSTOCK_LICENSE.
  • An MCP tool called without the licence says the same in its error result. It also shows in the tool list with a note on what it needs.

Paying

Payments are handled by Polar, the reseller and merchant of record. Polar also takes care of VAT and invoices. You can cancel at any time from the link in the receipt. After you pay, Penstock notices by itself and sends a sign-in code to the address that paid. See Buying and signing in.

Free Pro for students, teachers and open-source maintainers

Students, teachers and open-source maintainers can get Pro for free. When the application link is set up, the licence dialog, the message that explains a paid feature, and penstock license show it. See Buying and signing in.

Common problems

A feature that worked yesterday now asks me to buy Pro.
Your 30-day trial has ended, or your licence was released or ended. Run penstock license to see which licence this machine has.
It works on my laptop but the pipeline says it needs Team.
That is the rule: a pipeline needs Team for every paid feature. penstock init --ci writes a pipeline for the licence on the machine that ran it, so its first run does not fail on something nobody bought.
Which plan do I need for the review bot?
Team in a pipeline. Pro is enough to run it on your own machine.
