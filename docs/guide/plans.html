Plans and licence

Penstock is free on the JetBrains Marketplace, and everything a modeller needs stays free. Pro and Team add the parts that save a team real time — laying a diagram out, proving it runs, documenting it, reviewing it in a pull request. Every new machine starts with thirty days of Pro.

One rule

A paid feature needs Pro on a developer's machine and Team inside a pipeline, which is any run with CI set. There are no exceptions per feature or flag: the review bot, SARIF and annotations, baselines and report run locally on Pro, and every paid command in a pipeline needs Team.

What each plan includes

FreeThe editor with the Classic, Camunda 7 and Camunda 8 profiles, the properties panels, the DMN and form editors, element templates and the template marketplace, scripts in an IDE tab, jumping from a diagram to its Java code, token simulation, the drawing check, bpmnlint, deployment, export and the hand-drawn look. In the terminal: check with its drawing and rules sections, fmt, diff, export, show, deploy, doctor.
Pro
€3 a month or €30 a year		Auto layout; flow analysis, which finds deadlocks, branches that run twice, steps that can never run and loops with no way out, and shows the path that leads there; process scenarios, every distinct way through a process with the conditions it takes, and a JUnit test for each that takes it; documentation for every process; the visual diagram diff in version control; modelling conventions from penstock.yaml; pictures of what changed; editing from the command line and the MCP server for AI agents; and, on your machine, the pull request report, check baselines and findings as SARIF or GitHub annotations.
Team
€12 a month or €120 a year		Everything in Pro, in a pipeline as well: the review bot in pull and merge requests, the pull request report, check baselines, findings as SARIF or GitHub annotations, and every other paid command inside CI.

A paid feature you have not bought says what it does and offers to buy it or to sign in, at the moment you reach for it. Nothing else in the editor changes.

Buying

In the IDE, click Penstock in the status bar or choose Tools | Penstock Licence…. Signing in is one field, E-mail or licence key, with Buy Pro beside it and a link to buy Team. In a terminal, run penstock license buy (or penstock license buy team). The checkout opens in your browser; yearly billing is selected, and monthly is one click away. Once the payment goes through, Penstock notices by itself and sends a sign-in code to the address that paid; type it in and the licence is active. There is no key to copy.

Payments are handled by Polar, the reseller and merchant of record, which also takes care of VAT and invoices. Cancel at any time from the link in the receipt.

One licence for the IDE and the terminal

The licence lives in ~/.penstock, and the editor and penstock both read it: sign in once on a machine and both are licensed. On another machine, type the address you bought it with into the sign-in field - it gets a code - or run penstock license login. A key works in the same field too, or with penstock license activate <key>.

A licence covers a number of machines at once — three for Pro, ten for Team. Signing in again on the same machine, after reinstalling the IDE for example, reuses its place rather than taking a new one. When every place is taken, signing in lists the machines and when each was activated, and frees the one you pick. Release This Machine or penstock license logout does the same by hand.

The licence is checked once a day and keeps working for thirty days without a connection.

In a pipeline

A pipeline does not sign in. Copy the key with Copy Key for CI, or print it with penstock license key, and store it as a secret named PENSTOCK_LICENSE. The key is checked without taking a machine's place, and the pipelines penstock init --ci writes already pass it through, when the machine that ran it has Team; without Team it writes a pipeline that runs the free check, so its first run does not fail on a feature nobody has bought. A pipeline gets no trial.

Commands

license buy [pro|team]Open the checkout, wait for the payment and activate the licence.
license login [email]Sign in with the address you bought Penstock with.
license logoutRelease this machine so the licence can be used on another.
licenseWhich licence this machine has and where it comes from. license key prints the key for a pipeline; license activate <key> activates a key typed in by hand.
