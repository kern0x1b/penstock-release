Buying and signing in

How to try Pro, buy it, sign in on another machine, and use a licence in a pipeline.

The trial

The first time you use Penstock on a machine, that machine gets 30 days of Pro. You do nothing. The status bar at the bottom of the IDE shows Penstock Pro trial: 27d. When the trial ends it shows Penstock Free. The trial is stored on the machine, in ~/.penstock/trial.json. It needs no network. A pipeline gets no trial.

Buy Pro or Team

In the IDE

  1. Click Penstock in the status bar, or choose Tools | Penstock Licence….
  2. Press Buy Pro. For Team, press the link Buy Team, for pipelines and the review bot.
  3. The checkout opens in your browser. Yearly billing is selected. Monthly is one click away.
  4. Pay. Penstock notices the payment by itself and sends a sign-in code to the address that paid.
  5. Type the code in. The licence is active. There is no key to copy.

You can also reach the same step from a paid feature: the message that explains it has a Buy Pro button.

In a terminal

penstock license buy          # Pro
penstock license buy team     # Team

The command opens the checkout, prints its address, and waits up to an hour for the payment. When the payment goes through it asks for the code that was sent to your e-mail. It needs a terminal to answer in.

Sign in on another machine

  1. Open the licence dialog, or run penstock license login.
  2. Type the address you bought Penstock with. A key works in the same field too.
  3. An e-mail brings a code. Type it in.
  4. Penstock finds your best licence and activates it on this machine.

The IDE and the command line share the licence. Sign in once on a machine and both are licensed. Both read ~/.penstock/license.json.

How many machines

A licence covers a number of machines at once. Signing in again on the same machine, for example after reinstalling the IDE, reuses its place. It does not take a new one. When every place is taken, signing in lists the machines and when each was activated. Pick the one to free, and this machine takes its place.

To free a machine by hand, choose Release This Machine in the licence dialog, or run penstock license logout.

Check your licence

$ penstock license
Pro   Pro trial, 27 days left

penstock license buy   buy Pro        penstock license login   already bought

The line says which plan this machine has and why. Other forms:

penstock license keyPrints the key, for a pipeline. Keep it secret.
penstock license activate <key>Activates a key you type in by hand.
penstock license logoutReleases this machine.

When the licence is checked

  • Once a day, in the background.
  • It keeps working for 30 days without a connection. The status shows how many days are left.
  • After 30 days without a check, the machine falls back to Free until it connects once.
  • If the subscription ended, or the licence was released from another place, the machine falls back to the trial, or to Free when the trial is over.

In a pipeline

  1. On a machine that has Team, run penstock license key. Or press Copy Key for CI in the licence dialog.
  2. Store the key in a secret named PENSTOCK_LICENSE in your CI system.
  3. Pass it to the job as an environment variable. The pipelines that penstock init --ci writes already do it, when the machine that ran the command has Team.

The key is checked, and it takes no machine's place. Without Team on the machine, init --ci writes a pipeline that runs only the free checks. See Pipelines, reports and the bot.

Free Pro for students, teachers and open-source maintainers

Penstock offers Free Pro to students, teachers and open-source maintainers. When the application address is set, it appears in three places: the licence dialog (a link Free Pro for students, teachers and open-source maintainers: apply), the message that explains a paid feature (a button Apply for Free Pro), and the output of penstock license. While no address is set, nothing about it is shown.

The application address is not yet published on this page. If you qualify and see no link, open an issue on the support tracker and say which group you are in.

What you see

  • After signing in: Penstock Pro is active on this machine. The editor in your IDE uses it too.
  • The status bar says Penstock Pro or Penstock Team instead of Penstock Pro trial.
  • penstock license prints the plan and where it comes from.

Common problems

"There is no Penstock licence bought with that address."
Sign in with the exact address you paid with. Or buy with penstock license buy.
"That code is wrong or has expired."
Ask for a new code. You have three tries per code.
"Signing in needs a terminal to answer in."
You ran license login or license buy in a place without a terminal, for example a CI job. In a pipeline set PENSTOCK_LICENSE instead.
"PENSTOCK_LICENSE is not a valid Penstock key."
Copy the key again with penstock license key. Check there is no space or line break around it.
Every machine is in use.
Pick one to free when signing in, or press Release This Machine on a machine you no longer use.
The licence service could not be reached.
Check your network and proxy. An active licence keeps working for 30 days offline.
