Documentation

Penstock is a BPMN 2.0 editor that runs inside JetBrains IDEs. These eleven pages cover it from installation to troubleshooting. Read them in order the first time, or go straight to the one you need.

Pages

Getting started Requirements, installing from the Marketplace, which files open in the diagram editor, choosing the engine profile, and a tour of the toolbar and the BPMN Project tool window.
Engine profiles What separates the Classic BPMN 2.0, Camunda 7 and Camunda 8 profiles, which namespaces each one writes into the XML, and what else the choice changes.
BPMN elements Every element the editor can draw: the four tools and ten elements on the palette, the searchable Create element catalogue, what each task, gateway, event and data element is for, and how to change one element into another.
Editing a diagram Working on the canvas and in the properties panel: the palette, the XML tab, editing a script in its own IDE tab, copy and paste, undo and redo, the minimap, token simulation, export, and comparing two revisions of a file as two diagrams side by side.
Element templates Which JSON files Penstock reads as element templates — the list you keep in settings, not a scan of the project — what it does with each one, and how the bundled connector browser, shown under Camunda 8, writes a template into the project and adds it to that list.
Validation Running the project's own bpmnlint: the three paths it needs, the trusted project requirement, and what each message in the Run window means.
Diagram check The panel that lists what is wrong with the drawing — overlapping shapes, connections that do not reach what they connect, elements outside their pool — points at each one on the canvas, and separates real problems from readability.
Deployment Sending the open diagram to a Camunda 7 or Camunda 8 engine, the authentication methods for each, and where the credentials are stored.
Auto layout What the layout engine does to a diagram and what it will not produce, the preview that shows the result before it is applied, and the spacing values you can set in .bpmnlayoutrc.
Command line The same checks and the same deployment from a terminal or a pipeline, with a wrapper that pins the version and SARIF output GitHub reads directly.
Configuration One hand-written penstock.yaml per project, overridden by the one nearest the diagram, with a schema the IDE reads for completion - and the settings page it replaces.
Troubleshooting Fixes for a blank editor, validation that does nothing, failed deployments and missing element templates, plus answers to common questions.

If a page does not answer your question, open an issue on the support tracker.
