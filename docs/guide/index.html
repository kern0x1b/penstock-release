Documentation

Penstock is a BPMN, DMN and form editor that runs inside JetBrains IDEs. These sixteen pages cover it from installation to troubleshooting. Read them in order the first time, or go straight to the one you need.

The editor

Getting started Requirements, installing from the Marketplace, which files open in which editor, how the engine is chosen, the two example projects, the first-run tour, and the tool window.
Engine profiles What separates the Classic BPMN, Camunda 7, Camunda 8, Operaton and CIB seven profiles, which namespace each one writes into the XML, and what else the choice changes.
BPMN elements The palette and the searchable Create element catalogue: every task, gateway, event and data element, and how to change one element into another.
Editing a diagram The toolbar, the command palette and pinning an action to it, the palette, the XML tab, a script in its own IDE tab, copy and paste, token simulation, transaction boundaries, export, and comparing two revisions as two diagrams.
The sidebar The Properties, Scenarios, Problems, Monitor and Code tabs of the diagram editor, the tabs of the decision and form editors, the Scenarios review drawn over the diagram, and the live form preview.
Check and problems The card over the canvas, the Problems tab, and what each group of findings means: the drawing, how the process runs, the modelling rules, what the engine can run, the code, and the Camunda 7 to Camunda 8 result.
Deployment The Deploy popover, the Connection dialog, profiles, credentials and hooks, and what an engine says when it refuses.

Getting a diagram in and out

Element templates Which JSON files Penstock reads as element templates, and the connector browser, whose catalogue is downloaded from GitHub on demand and cached for the IDE and the command line.
Camunda 7 to Camunda 8 What does not carry over, why and who does it, the free report, the conversion preview with the visual diff, job worker skeletons from your delegates, and penstock migrate.
Sharing and importing Share as HTML, one file that opens offline in any browser, and Import diagram from draw.io, Visio, Signavio and Bizagi. Both free.
Auto layout What the layout engine does to a diagram and what it will not produce, how to run it, and how to take it back.

The project and the pipeline

Validation bpmnlint without setup, a project .bpmnlintrc that replaces it, rules from plugins, the engine compatibility rules, and where the findings appear.
Configuration One hand-written penstock.yaml per project, overridden by the one nearest the diagram, with a schema the IDE reads for completion - and the personal view settings kept outside it.
Command line The same checks and the same deployment from a terminal or a pipeline, scenarios and their runs, the conversion, sharing and importing, the MCP server, the review bot, and a wrapper that pins the version.

The rest

Plans and licence What is free, what Pro and Team add, the one rule that decides which a feature needs, buying and signing in, the thirty-day trial, and the signed token that is checked offline.
Troubleshooting Fixes for a blank editor, a diagram that will not open, lint findings that do not appear, failed deployments and missing element templates, plus answers to common questions.

If a page does not answer your question, open an issue on the support tracker.
