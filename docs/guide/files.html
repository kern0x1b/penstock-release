Files Penstock reads and writes

A complete list of the files Penstock reads, writes and keeps, and where each one lives.

Free

On this page

  • In your project
  • In your home folder
  • Not in a file
  • How to remove everything
  • Common problems

In your project

FileWhat it isCommit it?
penstock.yaml (also .yml, .json)The project's settings. Read from every folder from the root down to the diagram.Yes
penstock.local.yamlThis machine's settings, and the engine address you type into the Connection dialog.No. Penstock adds it to .gitignore.
.bpmnlintrcYour bpmnlint rules.Yes
.camunda/element-templates/Element templates, read from next to a diagram and every folder above it.Yes
penstockw, penstockw.cmd, penstock/wrapper/penstock-wrapper.propertiesThe command line wrapper and the version it pins.Yes
penstock-baseline.jsonThe problems the project already has. Written by penstock check --update-baseline.Yes
.penstock/runs/Traces of test-case runs. It has its own .gitignore.No
.penstock/images/Pictures from penstock diff --images and penstock report.No
penstock-report.mdThe pull request report written by penstock report.No
.bpmn, .dmn, .formYour diagrams, decisions and forms. Penstock edits them in place.Yes
.idea/bpmn-project.xmlLegacy settings of older versions. Penstock offers to move them to penstock.yaml.No longer needed

In your home folder

Penstock keeps its personal files in ~/.penstock. If the environment variable PENSTOCK_HOME is set, they are under that folder instead. The plugin and the command line share them.

FileWhat it is
preferences.jsonYour toolbar choices, Sketchy Drawing, tree or flat view in the tool window, the last export format, and whether the tour was shown.
license.jsonYour licence key and the time it was last checked. Readable only by you.
trial.jsonWhen this machine's 30-day Pro trial started.
connectors/<release>/The Camunda connector templates downloaded from GitHub.
wrapper/dists/<version>/The command line versions the wrapper downloaded.
test-builds.jsonA list of test builds a test-case run deployed, so the next run can remove what an interrupted one left.

Not in a file

The password or client secret for a deployment profile lives in the IDE password safe. It is never written to a file.

How to remove everything

  1. Uninstall the plugin. See Installing.
  2. Delete ~/.penstock.
  3. In your projects, delete the files above that you do not want.

Common problems

My toolbar differs between two computers.
preferences.json is per machine. It does not sync.
I want the settings somewhere else.
Set PENSTOCK_HOME to another folder, for example on a shared drive. Then the IDE and the command line use that folder.
Git shows penstock.local.yaml as new.
Add it to .gitignore. penstock init does this for you.
