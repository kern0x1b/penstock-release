Getting started

Before you begin

You need Penstock installed. If you have not done that yet, follow Installing. It takes two minutes.

Start with the example project

The quickest way to see everything work is the example. It is a small order process with workers, a decision, a form and test cases. The example project explains every file.

  1. Make a new empty folder and open it in your IDE. You can also use a folder you already have, as long as it has no diagrams yet.
  2. Open the Penstock tool window on the left. When the project has no diagrams, it offers two examples: Camunda 8 order process and Camunda 7 order process. Press one. A dialog called Start from an example asks if it may write the files. Press Create. It never overwrites a file.
  3. Open src/main/resources/order-process.bpmn. The diagram appears.
  4. Press Check on the toolbar. The check card opens at the bottom right. A fresh example should have nothing wrong.
  5. Press Deploy on the right of the toolbar. The first time, Penstock asks for the engine address. Enter it and press Deploy again. Deployment has the details.

From a terminal, the same example is one command in an empty folder:

penstock init --example camunda-8

Start with your own diagram

  1. Open a .bpmn file. If you have none, create a file called process.bpmn and open it. An empty file is fine.
  2. If the diagram says nothing about its engine, one line appears above the canvas: Which engine runs this diagram? Press Camunda 8, Operaton, CIB seven, Camunda 7 or Plain BPMN. The answer is written to penstock.yaml in the project root. It is asked once.
  3. Draw. Drag elements from the palette on the left, or click an element and use the small pad next to it. Editing a diagram shows how.
  4. Select an element and fill in its properties on the right. The properties panel explains the groups.
  5. Press Check. Fix what it lists. Diagram check explains each kind of finding.

What you see

  • Toolbar along the top. Undo and Redo are on the left. Deploy is on the right. Everything else is in the More menu. See The toolbar and the More menu.
  • Palette at the left edge of the canvas, with the elements you can draw.
  • Canvas in the middle. It always uses the theme of the IDE.
  • Properties panel on the right, for the selected element.
  • Tabs at the bottom: BPMN Editor and Text.

Common problems

The Penstock tool window does not offer an example.
It offers examples only when the project has no diagrams. Use penstock init --example in an empty folder instead.
Deploy is missing from the toolbar.
Deploy is shown for Camunda 7, Camunda 8, Operaton and CIB seven projects. A Plain BPMN project has none. Change the engine in penstock.yaml.
The question about the engine did not appear.
It appears only for an empty diagram. A diagram that already says which engine it is for, or a project with engine in penstock.yaml, is not asked.
